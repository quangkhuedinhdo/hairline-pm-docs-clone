# Promotional Asset Specification

**Purpose:** Lifestyle-presentable promotional assets for social media and pitch decks\
**Audiences:** Potential customers · Providers\
**Total:** **2 sets · 16 images**

# Global Format

Applies to all **16 images**.

| Element          | Specification                                                                                                                 |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **Device**       | Mobile phone or laptop mockup, portrait orientation, device frame included                                                    |
| **Background**   | Clean gradient or solid brand-colour ground — **not** a lifestyle photo composite                                             |
| **Text Overlay** | One bold headline + one sub-line per image. No technical labels or UI annotations outside the screen.                         |
| **Screens**      | Must show realistic mock data — no empty states, placeholder text, or developer-facing labels.                                |
| **References**   | [https://s.letweb.net/s/dkmm25](https://s.letweb.net/s/dkmm25) [https://s.letweb.net/s/gl9977](https://s.letweb.net/s/gl9977) |
