Default: all surfaces selected for the target language. Patient App, Provider Dashboard, Admin Platform, Shared/Notification.
Generation mode
Prefill Missing Keys
Generate draft values only where the selected target language has no value. Existing values are not replaced.
Replace Entire Language
Generate replacement draft values for all selected target-language keys in the selected scope, except protected English/source values. Requires explicit confirmation — this can overwrite many existing draft values.
