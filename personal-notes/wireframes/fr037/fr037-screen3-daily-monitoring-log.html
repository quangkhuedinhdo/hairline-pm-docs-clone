Design Notes
Date picker disables future dates. Dots show dates that already have entries — picking one adds a second entry for that date.
Save disabled until Severity is set (required). Date defaults to today; Notes, Photos, Head Scan are optional.
Head Scan row routes to Screen 4 for guided 4-view capture, or lets patient select an existing case scan.
Multiple entries on same date are allowed. "Logged Days" counts the date once — not the number of entries.
Latest entry (14:32) is authoritative for severity trend and PDF. Earlier entry (09:17) stays visible and auditable — not hidden or deleted.
Edit / Delete available while case is active. All versions remain auditable per PRD business rule.
