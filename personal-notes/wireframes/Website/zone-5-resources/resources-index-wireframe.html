SEO design requirements (Brief §7)

  • Single H1 on page (hero headline)
  • Breadcrumb component present (§7.1)
  • Category sidebar = cluster navigation (§7.2)
  • Article counts support topical authority signalling
  • Newsletter email capture = SEO visitor conversion target (§2.4)
  • Pagination preferred over infinite scroll for crawlability
  • Each article card uses semantic article/heading markup

Interaction & responsive notes

  • Filter tabs + sidebar category list are in sync (same state)
  • Sidebar: sticky desktop / expandable accordion mobile
  • Grid: 3-col → 2-col (768px) → 1-col (360px)
  • Featured card: 2-col → stacked (768px)
  • URL reflects active filter: /resources?category=treatments
  • Article card hover: translateY(-2px) + shadow lift
  • Newsletter form: inline validation, success state with confirmation message
