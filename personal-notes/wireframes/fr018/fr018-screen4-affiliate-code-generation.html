Generate Affiliate Code
Create affiliate-bound discount codes for one affiliate, a selected set, or a filtered segment.
Generation Mode
Select how to target affiliates for this code generation run.
Single Affiliate
Generate one code for a single selected affiliate. Code name is entered manually. On submit, routes to the Promo Code Detail (Screen 6).
Selected Affiliates
Generate one distinct code per manually chosen affiliate. On submit, opens the Code Generation Results screen (Screen 4.1).
Filtered Segment
Generate one distinct code per affiliate matching a saved filter. System snapshots matched affiliate IDs at generation time.
Selected Affiliates and Filtered Segment modes open Screen 4.1 (Code Generation Results) after submit. Single mode confirms inline and routes to Screen 6 (Promo Code Detail).
