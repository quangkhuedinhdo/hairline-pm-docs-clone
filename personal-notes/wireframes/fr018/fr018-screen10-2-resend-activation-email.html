  • BR Rate limit: max 3 resend requests per hour per email address (prevents spam).

Screen Flow
Happy Path — Successful Resend
Affiliate opens login page → clicks "Didn't receive activation email?" → enters registered email → submits → generic confirmation shown → checks inbox → receives fresh activation link → proceeds to Screen 10.1 (Set Password).
Login Page → Screen 10.2 (Form) → Submit Email → Confirmation → Screen 10.1 (Set Password)
Alternative — Unknown / Already-Activated Email
Affiliate enters an email not found in the system, or an email for an account already activated. System shows the same generic confirmation without revealing whether the email exists or account status.
Screen 10.2 (Form) → Submit (unknown/activated email) → Generic Confirmation (same message)
Alternative — Rate Limited
Affiliate has already submitted 3 resend requests within the past hour. Further requests are blocked. The submit button is disabled and an explanatory warning is displayed. Affiliate must wait before trying again.
Screen 10.2 (4th+ attempt) → Rate Limit Warning → Submit Disabled
Admin-Side Resend (Screen 3)
Admin can also resend the activation email directly from the Affiliate Detail screen (Screen 3) via the "Resend Activation Email" action button — available only while Activation Status is "Invited". Same rate-limit and link-invalidation rules apply.
Screen 3 (Affiliate Detail) → Resend Activation Email (button) → Fresh Link Sent
