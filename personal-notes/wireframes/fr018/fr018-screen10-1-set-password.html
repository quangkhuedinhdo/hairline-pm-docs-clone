Screen Flow
Happy Path — Successful Activation
Affiliate opens activation email → clicks Set Password link (valid, unexpired) → enters strong, matching password → submits → account activated → redirected to portal login (Screen 9).
Activation Email → Screen 10.1 (Valid) → Set Password → Screen 9 (Login) → Screen 10.3 (Welcome)
Alternative — Expired / Used Link
Affiliate opens expired or already-used link → system shows explanatory message → affiliate requests new activation link → routed to Screen 10.2 (Resend Activation).
Screen 10.1 (Expired) → Request New Link → Screen 10.2 (Resend)
